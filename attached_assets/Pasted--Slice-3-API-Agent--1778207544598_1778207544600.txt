5. 开发成本也要控制
从截图看，你现在 Agent 开发成本已经非常高。

建议以后让 Agent 执行任务时限制：

2. 明确禁止无意义反复 typecheck
你们现在多次 typecheck 都撞已知旧错误。可以要求：

已知旧错误不要重复跑全仓库

关键节点做即可。每个小改动都审查，会增加成本。

4. 能本地确定的用脚本，不用 Agent 反复读代码
比如：

而不是让 Agent 全仓库探索。
