二、逐场景走查与测试详情
场景1：输入研究方向和主题 → 系统搜索和收集文献
走查路径：home.tsx 创建 Session → papers.tsx 搜索 → papers.ts API
表格
功能点	代码位置	测试结果	备注
创建研究方向Session	sessions.ts POST /sessions	✅	存储 name + description（研究方向主题）
OpenAlex主题搜索	papers.ts fetchOpenAlexWithRetry	✅	15秒超时 + 1次重试，区分504/429/502错误
关键词缓存	papers.ts searchCache Map	✅	15分钟TTL，减少重复API调用
通过DOI/URL精确查找	papers.ts POST /papers/lookup	✅	支持DOI、OpenAlex ID、arXiv ID、doi.org URL
批量导入BibTeX/RIS	papers.ts extractDoisFromCitations	✅	自动提取DOI并去重
PDF全文上传解析	papers.ts multer + pdf-parse	✅	25MB上限，解析为fullText用于后续 richer extraction
添加到Session	papers.ts POST /sessions/:id/papers	✅	关联保存，支持openAccessUrl
测试结论：该流程完整闭环，从主题输入到文献入库的全链路已打通。
场景2：读取文献的模型图 + 搜索模型图
走查路径：variables.ts 提取论文模型 + model-assistant.ts 图片/论文搜索
表格
功能点	代码位置	测试结果	备注
从论文文本提取模型结构	models.ts extractPaperResearchModel	✅	提取为typed causal graph（nodes+edges），缓存到papers.researchModel
提取formal hypotheses	variables.ts 提取prompt	✅	新增paperHypothesesTable，存储H1/H2a等假设、效应量、页码
网络搜索概念模型图	model-assistant.ts search-model-images	✅	SerpApi/Brave双源，AI扩展查询，hard negative过滤，AI relevance分类badge
搜索"含模型图"的论文	model-assistant.ts search-model-papers	✅	AI预判论文含模型图概率（high/medium/low）+ 中文理由
用户屏蔽不相关图片	model-assistant.ts image-blocklist	✅	按URL屏蔽，非按域名，不影响同出版社其他论文

关键发现：
已支持：系统能"读懂"论文模型结构（通过AI解析文本），也能从互联网搜索模型图。
未支持：无法直接把你项目里已有论文的PDF中的原图（Fig.1概念模型图）提取出来展示。这意味着用户已经添加的10篇论文里的模型图，系统"看"不到，只能去互联网上重新搜。

场景4：从研究方向基础上重组模型 + 给参考依据
走查路径：models.ts POST /sessions/:id/models/generate
表格
功能点	代码位置	测试结果	备注
理论骨架库	theoryTemplates.ts	✅	17个骨架（新增JD-R/COR/SET/LMX/SDT/SCT/RBV/DC/COI）
骨架智能推荐	theoryTemplates.ts recommendBackbones()	✅	根据DV关键词匹配dvHints，回退到默认8个
结构化操作符	theoryTemplates.ts STRUCTURAL_OPERATORS	✅	5个：EXTEND/INSERT_MODERATOR/PARALLEL_MEDIATORS/SWAP_MEDIATOR/THEORY_GRAFT
操作符约束描述	theoryTemplates.ts	✅	每个操作符带CONSTRAINT描述（如EXTEND要求共享变量、层级正向）
五级层级防跳链	theoryTemplates.ts CONSTRUCT_LAYERS	✅	stimulus→cognitive→affective→intention→behavior，禁止回跳
生成Prompt硬规则	models.ts prompt	✅	13条HARD RULES（操作符驱动、双操作符链式、≥3篇跨论文、尊重原方向、引用grounding、布局纪律、大小、多样性、层级顺序、一角色一变量、调节变量必须justification、假设级证据优先）
逐边参考依据	models.ts ModelEdge	✅	evidenceCitationText + 新增evidenceHypothesisId/effectSize/evidenceLocation/moderatorJustification
后验结构验证器	models.ts validate()	✅	检查操作符有效性、backbone、节点数(5-8)、边数(4-8)、跨论文数(≥3)、边引用有效性、证据长度(≥12字符)
自定义提示词降级	models.ts	✅	当userPrompt非空时，minDistinctPapers从3降到1，minNodes从5降到4，避免聚焦型prompt全被拒
学习偏好循环	models.ts + feedback.ts	✅	从generationFeedbackTable读取过去8条选择记录，注入prompt
失败详情反馈	models.ts + 前端	✅	rejected数组返回具体原因（如"duplicate operator pair"、"node count out of range"），前端toast展示
测试结论：模型生成是系统最强的模块。已经从"AI自由创作"升级为"约束驱动创作+后验验证"。

三、关键缺陷与Gap（按影响排序）
🔴 High Impact
表格
#	问题	影响	建议
1	无法从用户已添加的PDF中提取原始模型图	用户辛苦添加了10篇论文，系统却"看"不到里面的Fig.1概念模型，只能去互联网大海捞针	增加PDF图表提取pipeline：pdf→image渲染→GPT-4V筛选含框图页面→存paper_figures表
2	论文搜索只依赖OpenAlex单一数据源	某些领域（如教育学ERIC、医学PubMed）覆盖不足	增加Semantic Scholar、PubMed、CNKI等并行搜索源
3	图片搜索仍依赖通用搜索引擎索引	学术概念图在Google Images中稀疏，导致"搜不到符合主题和模型的图"	建立"论文图表库"作为图片搜索的主数据源（见#1），网络搜索作为补充
🟡 Medium Impact
表格
#	问题	影响	建议
4	canonicalize() 去重逻辑过于简单	"perceived trust"和"trust perception"会被视为不同变量	升级为embedding-based语义相似度聚类
5	没有"模型对比"并排视图	用户难以比较两个候选模型的差异	增加A/B对比页面：差异边红色高亮、共有边绿色
6	缺少协作/分享功能	博士论文需要导师审阅模型	增加只读分享链接+导师批注
🟢 Low Impact
表格
#	问题	影响	建议
7	AI生成模型偶有被验证器批量拒绝	用户看到"AI did not produce any structurally valid models"会感到困惑	增加"半通过"模式：展示被 rejected 的模型并标注具体违规项，让用户选择是否放宽规则接受
