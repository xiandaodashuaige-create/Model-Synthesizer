2. 一个小 bug / UX 不一致：Gap Report 按钮显示“重新生成”，但后端会直接返回缓存
前端逻辑：

如果 gapReport 存在，按钮显示 regenerate / 重新生成
但后端逻辑是：

if gapReport.version === landscapeVersion:
  return cached gapReport
所以用户点“重新生成”时，其实不会真的重新生成，只会返回缓存。

这不是严重 bug，但会让用户误解。

建议二选一：

方案 A：改按钮文案
刷新报告
或：

查看最新报告
方案 B：支持 force 参数
POST /sessions/:id/landscape/gap-report?force=true
用户点“重新生成”时才强制调用 AI。

我建议先做 A，省钱且简单。
